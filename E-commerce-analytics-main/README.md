# E-Commerce Customer Purchase Analytics

## Customer Purchase Analysis and Product Recommendation System

A Hadoop ecosystem project using **HDFS, Pig Latin and Apache Hive** to analyze e-commerce transaction data, customer behavior and product relationships.

### Project Workflow
1. Import e-commerce transaction data into HDFS
2. Create Hive database and transaction tables
3. Clean and preprocess data using Pig Latin
4. Analyze monthly purchase trends using HiveQL
5. Identify frequently bought-together products
6. Generate Top-5 product recommendations
7. Perform customer segmentation and behavior analysis
8. Evaluate recommendation effectiveness

### Key Results
